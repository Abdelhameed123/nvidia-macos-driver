## ⚙️ How It Works

The driver works by adding support for NVIDIA GeForce cards to macOS Sequoia. When you install the driver, macOS can use the graphics card for Metal-based tasks. Metal is the part of macOS that handles graphics for many apps, including games, video editors, and design tools.

The driver package includes files that tell macOS how to communicate with the NVIDIA card. These files are often called kexts, which stands for kernel extensions. A kext is a small piece of software that runs at a low level in the operating system. It helps the system use hardware that it does not natively support.

The driver also includes support for OpenCore, which is a bootloader used in some custom Mac setups. OpenCore helps the computer start up and load the operating system. When the driver is used with OpenCore, it can be loaded during startup so that the graphics card is available from the beginning.

Vulkan support is included for apps and games that use the Vulkan graphics technology. Vulkan is an alternative to Metal and is used by some cross-platform games. The driver helps translate Vulkan commands so that they work with the NVIDIA card on macOS.
